# منصة كنوز — دليل النشر الكامل (خطوة بخطوة)

هذا الدليل ينقل المنصة من هذا المجلد إلى الإنترنت على **حساباتك أنت**، بحيث تبقى ملكك بالكامل وتعمل حتى بلا أي اشتراكات مدفوعة. الوقت المتوقع: **20–30 دقيقة**.

> كل ما تحتاجه: بريد إلكتروني + بطاقة بنكية (لشراء النطاق فقط، ~10$ سنويًا). الاستضافة والمستودع مجانيان.

---

## الخطوة 1: إنشاء حساب GitHub (مجاني)

1. افتح <https://github.com> واضغط **Sign up**.
2. أدخل بريدك الإلكتروني، واختر كلمة مرور واسم مستخدم (مثال: `kunooz-qatar`).
3. أكّد البريد الإلكتروني بالرمز الذي يصلك.

## الخطوة 2: رفع ملفات المنصة إلى GitHub

1. بعد دخولك، اضغط زر **+** أعلى اليمين ← **New repository**.
2. **Repository name**: اكتب `kunooz` ← اختر **Public** ← اضغط **Create repository**.
3. في الصفحة التالية اضغط رابط **uploading an existing file**.
4. اسحب **كل محتويات مجلد `site`** (الملفات والمجلدات: index.html وassets وdata وfiles …) إلى الصفحة. (إن منعك المتصفح من سحب المجلدات، ارفعها مجلدًا مجلدًا، أو استخدم زر **Add file ← Upload files** مع سحب المجلدات كاملة.)
5. اضغط **Commit changes** الأخضر أسفل الصفحة وانتظر اكتمال الرفع.

## الخطوة 3: شراء النطاق konoz.com

1. افتح <https://dash.cloudflare.com/sign-up> وأنشئ حساب **Cloudflare** مجانيًا ببريدك، وفعّله من رسالة التأكيد.
2. من لوحة التحكم اختر **Register Domain** (أو **Domain Registration ← Register Domains**).
3. ابحث عن `konoz.com` وأضفه إلى السلة وأكمل الدفع (السعر من Cloudflare بسعر التكلفة تقريبًا، ~10$ سنويًا بلا زيادات).
4. بعد الشراء سيجهز النطاق تلقائيًا داخل حسابك (لا تحتاج أي إعداد إضافي الآن).

> بديل: إن كان konoz.com محجوزًا، جرّب `konoz.net` أو `kunooz.com` أو `konozqatar.com` — أي نطاق يعمل، والمنصة لا تتأثر بالاسم.

## الخطوة 4: ربط المستودع بـ Cloudflare Pages (الاستضافة المجانية)

1. في لوحة Cloudflare اختر من القائمة اليسرى **Workers & Pages** ← **Create** ← تبويب **Pages** ← **Connect to Git**.
2. اضغط **Connect GitHub** ووافق على التصريح، ثم اختر مستودع `kunooz`.
3. اضغط **Begin setup**، وفي صفحة الإعدادات:
   - **Project name**: `kunooz`
   - **Production branch**: `main`
   - **Framework preset**: اتركه **None**
   - **Build command**: اتركه **فارغًا**
   - **Build output directory**: اتركه `/` (أو فارغًا)
4. اضغط **Save and Deploy**. بعد دقيقة تقريبًا تعطيك المنصة رابطًا مجانيًا مثل: `https://kunooz.pages.dev` — **افتحه وتأكد أن المنصة تعمل**.

## الخطوة 5: ربط النطاق konoz.com بالمنصة

1. داخل مشروع `kunooz` في Cloudflare Pages افتح تبويب **Custom domains** ← **Set up a custom domain**.
2. اكتب `konoz.com` واضغط **Continue** ثم **Activate domain**.
3. لأن النطاق اشتريته من Cloudflare نفسها، يتم الربط **تلقائيًا** خلال دقائق (لا DNS يدوي).
4. افتح <https://konoz.com> — المنصة تعمل الآن على نطاقك مع شهادة أمان HTTPS تلقائية.

> أضف أيضًا `www.konoz.com` بنفس الطريقة إن رغبت (اختياري).

---

## ماذا بعد؟

- **تحديث المحتوى**: أي تعديل ترفعه إلى GitHub (من زر **Add file ← Upload files** داخل المستودع) يُنشر تلقائيًا على الموقع خلال دقيقة. راجع ملف **دليل-التحديث.md**.
- **التكلفة السنوية الوحيدة**: تجديد النطاق (~10$). الاستضافة والمستودع مجانيان للأبد.
- **النسخ الاحتياطي**: ملفاتك في ثلاثة أماكن دائمًا: جهازك، GitHub، Cloudflare.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| الموقع يفتح صفحة بيضاء | تأكد أنك رفعت **محتويات** مجلد site وليس المجلد نفسه (يجب أن يكون index.html في الجذر) |
| «تعذر تحميل البيانات» | تأكد أن مجلد `data` رُفع كاملًا وأن الأسماء بحروف صغيرة |
| أسماء عربية مشوهة في روابط | لا تقلق — أسماء الملفات على الخادم إنجليزية، والأسماء العربية تظهر للزائر عند التنزيل فقط |
| النطاق لا يعمل بعد ساعة | راجع تبويب Custom domains في Pages وتأكد أن الحالة Active |
